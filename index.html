Currency Standardizer Regex

Extracts float values, converts formats: e.g., $ 1.250,50 -> 1250.50

Vendor Name Cleaner Heuristic

Strips inc, corp, llc, extra transaction trailing codes from vendor names.

/(\s+ltd|\s+inc|\s+llc|\s+corp|#\d+)/gi
Date Normalizer Regex

Parses multiple regional formats (DD/MM/YYYY, MM-DD-YY) into standardized ISO format.

/(\d{1,2})[\/\-](\d{1,2})[\/\-](\d{2,4})/
